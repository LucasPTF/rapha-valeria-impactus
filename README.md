# Workshop de Ozonioterapia Impactus

Página de vendas desenvolvida para o projeto de Rapha e Valéria, do Instituto Impactus.

## Tecnologias

Next.js, React, TypeScript e CSS responsivo.

## Rotas

* `/a1`
* `/a2`
* `/a3`
* `/obrigado`

As três páginas de vendas compartilham a mesma estrutura e diferem somente na comunicação da hero.

## Execução local

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm start
```

## Checkout

Defina `NEXT_PUBLIC_CHECKOUT_URL` no ambiente de publicação quando o endereço oficial estiver disponível.
